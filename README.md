## Versions

firebase-tools: v15.35.0

## Steps to reproduce

2. Run `firebase deploy --dry-run --only "functions:codebase-a:helloWorldA_1,functions:codebase-a:helloWorldA_2`, which only deploys functions from `codebase-a`
